# UE Project Docusaurus App

This folder contains the Docusaurus app that renders the repo-root `../Docs` tree.

## Local Development

```bash
npm install
npm start
```

## Production Build

```bash
npm run build
npm run serve
```

## Important

- Author docs in `../Docs`, not in `website/docs`.
- `sidebars.ts` is the thin autogenerated shell; normal doc navigation comes from `Docs/` plus `_category_.json` and `sidebar_position`.
- Deployment metadata lives in `docusaurus.config.ts`.
- Installer-selectable theme presets live in `theme-presets/`; install/update copies the selected preset into `src/css/custom.css`.
- Install/update also stamps project branding into `docusaurus.config.ts` based on the selected `.uproject`.
- Use `ue-tools docs start` and `ue-tools docs stop` from the repo root for the normal local dev server flow.
- Use `ue-tools docs status` to inspect the tracked dev server and `ue-tools docs doctor` to check local docs prerequisites.
- Use `ue-tools docs` from the repo root for normal docs scaffolding, validation, and Docusaurus script passthrough.
