# Docs Home

This site starts with two domains so standards and project-specific docs do not fight for the same sidebar.

## Domains

### Workflow & Standards

Shared setup, workflow, testing, coding standards, docs tooling, and AI context.

- [Open Workflow & Standards](./WorkflowStandards/README.md)

### Project Docs

Project-specific specs, design notes, system docs, production notes, and team runbooks.

- [Open Project Docs](./ProjectDocs/README.md)

## Site Administration

Need to change theme, branding, overrides, or create a new domain?

- [Open Site Settings](/docs/?siteAdmin=1)

## Conventions

- Keep long-form content in `Docs/`.
- Keep Docusaurus shell and theme behavior in `website/`.
- Prefer `_category_.json`, landing `README.md` pages, and autogenerated sidebars over hand-maintained navigation.
- Update docs in the same branch as the behavior they describe.
