# Configuration Catalog

## Runtime and configuration files

| File | Producer | Consumer | Key fields | Generated | May become stale | Security relevance |
|---|---|---|---|---|---|---|
| `payload/ue-tool-suite.manifest.json` | source-controlled | installer | `managedItems`, `managedTextItems`, `legacyCleanupPaths` | no | no | controls overwrite/remove scope |
| `payload/Scripts/UETools/UETools.psd1` | source-controlled | PowerShell module loader | `RootModule`, `NestedModules`, `PowerShellVersion`, `FunctionsToExport` | no | low | defines module surface/version metadata |
| `payload/website/package.json` | source-controlled | npm, docs CLI, CI | scripts, dependencies | no | low | dependency and script contract |
| `payload/website/package-lock.json` | source-controlled | npm ci, installer/init | resolved package graph | no | low | install reproducibility |
| `payload/website/docusaurus.config.ts` | source-controlled | Docusaurus | docs path, proxy target, navbar/footer/customFields | no | low | proxy target and site route behavior |
| `payload/website/sidebars.ts` | source-controlled | Docusaurus | sidebar export | no | low | navigation shape |
| `payload/website/theme-presets/theme-catalog.json` | source-controlled | GUI, docs theme commands, Site Settings | theme ids and metadata | no | low | allowed theme values |
| `Docs/_domains.json` | user/source-controlled in installed repo | domain catalog, API | domain list, positions, ownership | no | yes | wrong values affect move/nav behavior |
| section `_category_.json` | source-controlled or generated by migration | Docusaurus, API | label, position, link, custom props | mixed | yes | mutation target for ordering and section metadata |
| markdown front matter | source-controlled/user-authored | Docusaurus, API | title, slug, sidebar position, `unlisted` | no | yes | visibility and route behavior |
| `.ue-tools/state/...docs server entries...` | docs lifecycle | docs status/start/stop | PID, root PID, URL, log paths, args | yes | yes | stale state can mislead lifecycle tooling |
| `website/static/ue-tools/editor-runtime.json` | docs lifecycle | runtime discovery frontend | `apiUrl`, `applicationId`, `apiVersion`, `repoRoot`, `docsRoot`, `processId` | yes | yes | core trust input for frontend authoring |
| installed docs ledger JSON | installer | next installer update | managed docs file list and hashes | yes | yes | protects preserve-first docs updates |
| installed website ledger JSON | installer | next installer update | managed website file list and hashes | yes | yes | protects managed website cleanup/update |

## Key configuration values

| Key | Type | Default or current value | Source | Consumers | Effect | Validation example |
|---|---|---|---|---|---|---|
| `manifestVersion` | number | `1` | `payload/ue-tool-suite.manifest.json` | installer | payload schema version | JSON parse |
| `payloadVersion` | string | `1.0.0` | manifest | installer | payload identity | JSON parse |
| `docsManagedFileIndexPath` | string | `docs-managed-file-index.json` | manifest | installer | installed docs ledger location | installer path join |
| `websiteManagedFileIndexPath` | string | `website-managed-file-index.json` | manifest | installer | installed website ledger location | installer path join |
| `PowerShellVersion` | string | `5.1` | `UETools.psd1` | module metadata | declares baseline | manifest field |
| `docsAuthoringProxyPath` | string | `/__ue_docs_api__` | `docusaurus.config.ts` | frontend dev proxy | proxy route prefix | hard-coded constant |
| API default port | number | `38473` | `UEToolSuite.Docs.psm1`, `runtimeDiscovery.ts` | lifecycle and frontend fallback | local API endpoint | port parse/health probe |
| API application id | string | `UEToolSuiteDocsEditorApi` | same | lifecycle and frontend | runtime identity | health comparison |
| API capability version | number | `2` | same | lifecycle and frontend | protocol compatibility | health comparison |
| runtime probe timeout | number | `1500` ms | `runtimeDiscovery.ts` | frontend | health timeout threshold | controller/probe helpers |
| retry delays | number[] | `1000,2000,5000,10000,30000` | `runtimeDiscovery.ts` | frontend | auto-retry backoff | `getRetryDelayMs` |
| connected poll interval | number | `5000` ms | `runtimeDiscovery.ts` | frontend | re-probe while connected | controller |
| docs path | string | `../Docs` | `docusaurus.config.ts` | Docusaurus | docs content root | Docusaurus config |
| route base path | string | `docs` | `docusaurus.config.ts` | Docusaurus | public docs URL base | Docusaurus config |
| excluded docs globs | string[] | `Current`, `Templates`, `*.template.*` patterns | Docusaurus config and `domainCatalog.ts` | build and catalog | excludes authored templates/current docs | filter functions |
